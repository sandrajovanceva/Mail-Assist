# MailAssist

MailAssist is an AI-powered email assistant developed as a graduation thesis project. It connects to Gmail to organize emails, highlight messages that need attention, summarize conversations, and draft personalized replies using Google Gemini.

Users can review and edit replies, teach the assistant their writing style, check calendar availability, and ask questions about their inbox through a built-in chat assistant.

Built with React, TypeScript, FastAPI, and SQLAlchemy. Evaluation scripts are available in [`eval/`](eval/README.md).
